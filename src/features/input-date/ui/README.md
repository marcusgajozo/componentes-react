# InputDate

Componente de entrada de data e datetime-local baseado no input nativo do navegador.

## Uso

```tsx
import { InputDate } from "./ui";

<InputDate label="Data" type="date" />;
```

## Recursos

- Suporta `date` e `datetime-local`
- Mantém o comportamento nativo do navegador
- Ícone de calendário inline em SVG próprio
- Compatível com `react-hook-form` via `FormInputDate`
